# images/

Drop your real photo here, e.g. `rijo_varghese.jpg`, then in `index.html`
swap the `.portrait-placeholder` block for:

```html
<img class="portrait-image" src="images/rijo_varghese.jpg" alt="Rijo Varghese">
```

Keep any project screenshots here too (e.g. `images/cyberscan-preview.png`)
and reference them inside `.project-media` blocks in the Projects section.
